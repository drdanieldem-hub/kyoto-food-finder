# 🏯 Kyoto Food Finder

A self-contained, mobile-friendly Leaflet map of Kyoto's best restaurants,
sourced from **Tabelog** (3.4+) with optional **Hotpepper** enrichment
(English descriptions + photos).

**Live site:** https://drdanieldem-hub.github.io/kyoto-food-finder/

A Kyoto port of [tokyo-food-finder](https://github.com/drdanieldem-hub/tokyo-food-finder)
that **drops the Google Places API** (~$0.032/lookup → 3,000 restaurants ≈
$100). Tabelog's rating + review count filters just as well for popularity,
and Hotpepper's free API fills in English-friendly metadata.

---

## What's in the repo

| File / dir            | What it is |
|---|---|
| `index.html`          | The whole app. Self-contained. Generated by `build.py`. |
| `build.py`            | Generator. Reads `final_restaurants_merged.json` → `index.html`. Stdlib only. |
| `final_restaurants_merged.json` | Projected records ready for the map. |
| `scraper/`            | 4-stage data pipeline. See `scraper/README.md`. |
| `manifest.json`, `sw.js`, `icon-*.png` | PWA bits. |

## Quick start

```bash
cd scraper
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# Stage 1+2: Tabelog scrape (all 11 Kyoto wards)
python tabelog_kyoto_scraper.py all --delay 2.5

# Optional Stage 3: Hotpepper cross-reference for English names + photos
export HOTPEPPER_API_KEY=...           # free, no card: webservice.recruit.co.jp/register/
python hotpepper_crossref.py tabelog_kyoto_full_flat.json \
    final_restaurants_kyoto_hotpepper.json

# Stage 4: project into build.py shape
python to_map_format.py

# Generate the static site
cd ..
python3 build.py                      # → index.html
```

Then push to GitHub; Pages will deploy from `main`.

## Why this approach

| Choice | Reason |
|---|---|
| **No Google Places API** | Kyoto scraper ran $0.032/lookup × 3,000 = ~$100 last time. Free alternatives do the same job. |
| **Tabelog review count ≥ N as a popularity filter** | Replaces Google's "must have 100+ reviews" filter at zero cost. |
| **Hotpepper optional** | Owned by Gurunavi (Kyoto-based). Strong Kansai coverage. Free tier = 1,000 req/day, no card needed. |
| **Open now filter** | Disabled by default (we have no hours data without an additional scrape). Re-enable by adding a Hotpepper hours pull or a separate pass. |

## Regenerating the site

```bash
cd ~/kyoto-food-finder
python3 build.py                # rewrites index.html from the current JSON
git add -A && git commit -m "..." && git push origin main
```

GitHub Pages serves `main` automatically — no separate deploy step.

## Tech notes

- **No build system** — `build.py` is plain string concatenation that writes
  a fully self-contained HTML file with GeoJSON, marker metadata, and JS
  inlined.
- **Time handling** uses `Intl.DateTimeFormat` with `timeZone: 'Asia/Tokyo'`
  so any Japan-time-based UI (today row highlighting) stays correct
  regardless of the user's timezone.
- **Theme color** is `#be185d` (Kyoto temple red), distinct from Tokyo's
  `#10b981` (emerald).
- **Service worker** is a tiny offline-shell only; data is too large for
  full caching. First load requires network.
